# 离线文字识别组件

- Tesseract.js 7.0.0：`tesseract.min.js`、`worker.min.js`，Apache-2.0；许可证见 `TesseractJS-LICENSE.md`。
- tesseract.js-core 7.0.0：`tesseract-core*.js` 和 `*.wasm`，Apache-2.0；许可证见 `TesseractCore-LICENSE.txt`。
- `eng.traineddata.gz`、`chi_sim.traineddata.gz`：来自 `@tesseract.js-data/eng` 与 `@tesseract.js-data/chi_sim` 1.0.0。使用软件包中的 4.0.0 语言数据，许可为 MIT。

上述文件随 DoNote 安装包分发，文字识别在本机运行。
