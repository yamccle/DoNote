# DoNote 离线语音模型下载说明

DoNote 已内置语音识别运行组件；语音模型可自行下载。安装包不含模型。按用途保存到 DoNote.exe 同一目录的 `models\asr` 文件夹内，例如 `H:\DoNote\models\asr\small\model.bin`。目录名须与下方一致；不要把文件继续放在额外的嵌套目录中。旧版 `models\small`、`models\base` 等目录会在首次使用时自动迁移。

每次识别选择的模型都对应一个独立文件夹。只需下载需要使用的模型；其他模型的目录不要创建，未手动下载的模型仍会在选择时尝试联网自动下载。首次下载完成后，DoNote 使用该目录离线识别。若模型目录存在但不完整，DoNote 会提示缺少的文件或权重大小不正确。

## 模型清单

| 下拉框选项 | 本地文件夹 | 官方文件页（固定版本） | model.bin 大小 |
|---|---|---|---:|
| 轻量 · base | `models\asr\base` | [faster-whisper-base](https://huggingface.co/Systran/faster-whisper-base/tree/ebe41f70d5b6dfa9166e2c581c45c9c0cfc57b66) | 145,217,532 字节 |
| 轻量 · small | `models\asr\small` | [faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small/tree/536b0662742c02347bc0e980a01041f333bce120) | 483,546,902 字节 |
| 均衡 · large-v3-turbo | `models\asr\large-v3-turbo` | [faster-whisper-large-v3-turbo](https://huggingface.co/dropbox-dash/faster-whisper-large-v3-turbo/tree/0a363e9161cbc7ed1431c9597a8ceaf0c4f78fcf) | 1,617,884,929 字节 |
| 高准确 · large-v3 | `models\asr\large-v3` | [faster-whisper-large-v3](https://huggingface.co/Systran/faster-whisper-large-v3/tree/edaa852ec7e145841d8ffdb056a99866b5f0a478) | 3,087,284,237 字节 |

从所选模型文件页分别下载 `config.json`、`model.bin`、`tokenizer.json` 和词表：base、small 使用 `vocabulary.txt`；large-v3、large-v3-turbo 使用 `vocabulary.json`，并且还必须下载 `preprocessor_config.json`。保留原文件名，不要将 Git LFS 指针文本当作 model.bin。

例如 small 的目录结构如下：

```text
DoNote.exe
models/
  asr/
    small/
      config.json
      model.bin
      tokenizer.json
      vocabulary.txt
  translation/
    Qwen3-4B-Instruct-2507-Q4_K_M.gguf
```

如需核对 model.bin，使用 PowerShell 命令 `Get-FileHash -Algorithm SHA256 "H:\DoNote\models\asr\small\model.bin"`；应与所选模型对应的值一致：

- base：`d01c3014881c9c6f3133c182f3d2887eb6ca1c789a7538c5c007196857a0a6a9`
- small：`3e305921506d8872816023e4c273e75d2419fb89b24da97b4fe7bce14170d671`
- large-v3-turbo：`e76620f83d5f5b69efd3d87e3dc180c1bd21df9fbebacfd4335e5e1efcc018da`
- large-v3：`69f74147e3334731bc3a76048724833325d2ec74642fb52620eda87352e3d4f1`

本地识别不会将视频上传。字幕翻译优先使用 `models\translation` 中的本地大模型；只有主动选择“AI / API”时，字幕文本才会发送到你配置的服务。
