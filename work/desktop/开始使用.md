# DoNote · Windows 桌面版

## 第一次打开

解压整个压缩包，再双击文件夹里的 `DoNote.exe`。可为它创建桌面快捷方式。此版面向 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 运行时。若启动时提示缺少运行时，安装后重新打开即可。 [微软官方下载](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

工作台、笔记编辑、附件管理、PDF 批注、日志和提醒均可离线使用。在「本机保存」旁的齿轮或阅读器顶部可切换白天和夜间模式。夜间模式下 PDF 默认保持浅色纸张，只把外框和工具栏转暗。如需整页反色，可在「设置 → 外观 → 暗色下反转 PDF 页面」打开。

开场动画约 2.5 秒，随当前主题绘制签名和光迹。结束后进入工作台。按 `Esc` 可提前进入。「设置 → 外观 → 播放开场动画」记录在当前资料目录。系统开启减少动态效果时，DoNote 会直接进入工作台。

键盘快捷键：`Ctrl+F` 聚焦搜索，`Ctrl+N` 新建记录，不在输入框时按 `/` 也可以直接搜索。记录列表每页 20 条，可用底部分页条跳页。

打开「总览」即可从最近的 PDF、视频或网页阅读位置继续，也能查看即将截止的计划。总览仍支持自定义组件，记录可在下方查找。

各栏目在顶部保留搜索和本栏目常用操作。文件夹、周次和排序等选项在「筛选」。导入、文件夹管理和全文检索等操作在「更多」。资料库保留「添加」「筛选」「更多」和「多选」。

在总览的「全部记录」下，点「新建记录」或按 `Ctrl+N`，再选择记录类型。在具体栏目中，新建会直接打开相应类型。收起编辑器后，再点「新建记录」可继续填写。

填写标题和正文即可保存，计划另外提供起止日期。「添加附件」和「关联已有资料」位于正文前。需要让图片随正文显示时，使用正文工具栏的「插入图片」。标签、归档文件夹和其他字段位于「记录信息」。工作周报和学习周志分别从工作日志、学习日志栏目的工具栏进入。

在资料库和记录栏目点「新建文件夹」，默认建在当前位置。资料库可以通过路径或「上一级」返回。点文件夹的「…」可改名、新建子文件夹或移动。使用「管理文件夹」按名称或路径搜索。

移动时选择目标并核对完整路径。移动整个文件夹会一起保留其中的目录和资料，完成后可以撤销。要移动多份资料，进入资料库的「多选」，再点「移动到…」。单条资料可用右键菜单移动。

删除文件夹时，默认把直接子文件夹和记录移到上一级。要连同子文件夹一起删除，并将记录移入回收站，需在删除窗口勾选对应选项。

删除的记录会先进入**回收站**，保留 30 天。删除后点提示里的「撤销」可立即找回，之后可从「设置 → 资料与备份 → 回收站」或文献库「更多 → 回收站」恢复或彻底删除。

打开**「全文检索」**，可以离线搜索当前工作台的记录、PDF 正文、视频字幕和定格批注。点击结果可打开记录、跳到 PDF 页码或视频时间。首次遇到未索引的 PDF 时会提取正文，可暂停并继续。阅读器中按 `Ctrl+F` 可在当前 PDF 内查找。

本版首次启动是**空资料库**，账号为「默认用户」。如果之前在本机用过并想恢复到初始状态，先完全退出 DoNote，再运行 `tools\重置为初始状态.cmd`（会删除 `Data` 文件夹，建议先导出完整备份）。解压到新文件夹则天然是全新环境，不影响旧数据。

## 退出与更新

保存正在编辑的记录后，选择「本机保存」旁的齿轮，再点击「退出软件」。右上角关闭按钮也会提示确认。确认后，程序和由它启动的本机 AI 服务会关闭。

当前支持**本地 ZIP 更新**。打开「设置 → 检查更新包…」，选择新版 DoNote ZIP。软件会检查版本和文件完整性，确认后自动退出，备份旧版程序，安装新版本并重新打开。文献、附件和笔记留在原资料目录，不会在每次常规更新时复制。旧版程序备份保存在程序文件夹同级的 `DoNote-Backups` 中；若安装中断，会尝试恢复旧版程序。仅当更新包明确标记需要迁移资料格式时，安装器才会额外完整备份资料。建议平时在「设置 → 资料与备份」按需备份重要资料。

在「设置 → 资料与系统 → 检查在线更新」可以查看到最新版的更新路径和下载总量。保存正在编辑的记录后，点击「下载并自动更新」。DoNote 会先下载并校验所有更新包，再按顺序安装并重启一次。某一步安装失败时，更新器会尝试回退该步。再次检查时会根据已安装的版本重新选包。

如果当前版本还没有「检查更新包…」，需要**最后一次手动启用**：先完全退出 DoNote，再把本版 ZIP 解压到原程序文件夹，替换同名程序文件，之后打开原位置的 `DoNote.exe`。不要删除原文件夹，也不要删除其中的 `Data` 或 `data-location.txt`。启用后，今后的新版 ZIP 可直接从设置中安装。若使用自定义资料目录，更新后可在「设置 → 查看资料目录」核对。

旧快捷方式如果仍指向 `YamsOne.exe`，请将目标改为同一目录下的 `DoNote.exe`。请保留备份，确认新版运行和资料无误后再自行整理旧备份。

## 迁移网页版资料

1. 在原网页先保存正在编辑的记录。从「备份与资料夹」导出完整 ZIP 或自包含 JSON。
2. 在桌面版的「设置 → 资料与备份 → 备份与恢复」导入整份备份。ZIP 可以直接导入。
3. 有多个工作台时，在原网页逐个切换用户并分别导出。在桌面版创建或切换到对应用户后，再导入对应文件。核对记录、附件和阅读进度后，可留存原备份。

默认资料目录为程序旁的 `Data` 文件夹，包含所有本地工作台、附件、阅读进度和内置 AI 服务的资料。程序顶部「设置 → 资料与备份」可查看目录，也可选一个空文件夹。确认前先保存正在编辑的记录。程序关闭后，重新双击 `DoNote.exe`，它会复制资料并切换目录，原目录会保留。首次启动时会自动建立 `Data` 文件夹。覆盖更新时，原 `Data` 文件夹中的内容仍会保留。

## 云盘文件夹对齐

打开「设置 → 多端协同 → 云盘文件夹」，选择坚果云、Nextcloud 或 Google Drive 桌面版已经在同步的文件夹。不必填写网址和令牌。目录会对齐，所以另一台能看到有哪些文献。附件在打开某一份时再加载，不会把其他文献一并拉进本机。若云盘客户端还没把这一份传到本机，打开时会提示等待这一份。另一台电脑安装同一个云盘客户端，并选择同一个文件夹。外网上传由云盘客户端完成。

这不是云端备份。云端备份保存独立快照。文件夹对齐持续合并当前记录。

## 云端备份

打开「设置 → 资料与备份 → 备份与恢复 → 云端备份」，选择备份目标。每次备份生成一个独立版本，包含当前工作台的记录、附件、批注和阅读进度。运行中的资料仍保存在本机。

### 使用 Google Drive

1. 安装并登录桌面版 Google 云端硬盘。在 Windows 文件资源管理器打开「我的云端硬盘」，创建一个 DoNote 备份目录。也可选择已配置同步的本地目录。[Google 云端硬盘同步说明](https://support.google.com/drive/answer/13401938?hl=zh-Hans)
2. 在 DoNote 选择「Google Drive 桌面版同步目录」，选中该目录，点击「保存并检查」。如果流式盘符不可写，可选用 Google Drive 已设置同步的本地文件夹或镜像目录。
3. 在 Google 云端硬盘确认快照已同步。换电脑时登录同一账号，在 DoNote 中选取同一个云端硬盘目录，再刷新备份列表。

### 使用 WebDAV

在 DoNote 选择 WebDAV，填写服务商提供的 HTTPS 备份目录地址。如果目录需要登录，填写 WebDAV 的用户名和密码。保存设置后可以刷新列表来检查连接。

用 rclone 转接 Google Drive 时，先在 rclone 中授权你的 Google 账号，再把专用备份文件夹通过 `rclone serve webdav` 提供给本机。服务监听 `127.0.0.1` 时，在 DoNote 填写网关给出的回环地址和端口。备份或下载期间保持 rclone 运行。[rclone 的 Google Drive 接入](https://rclone.org/drive/) · [rclone WebDAV 文档](https://rclone.org/commands/rclone_serve_webdav/)

### 下载和恢复

1. 在云端备份列表选择版本，然后下载到本地。DoNote 会核对归档大小和 SHA-256 校验值，再解出备份文件夹。
2. 回到「备份与恢复」，点「从备份文件夹恢复」，选择下载成功后显示的目录，再确认导入。
3. 恢复会把新记录合并到当前工作台，跳过重复记录。需要单独查看某份历史备份时，可先创建空白工作台，再导入该备份。

每份备份是一份独立的完整快照；默认保留全部历史版本，也可在「备份目标 → 保留版本数」选择保留最近 3 / 5 / 10 / 20 份，新快照校验完成后会自动清理超限旧快照（不会触碰目录中的其他无关文件）。打包、下载和解包按块读写，使用本地临时空间。备份较大的工作台前，可先查看本地剩余空间和云盘配额。

## 常用入口

- **总览组件**可添加临时提醒、快速开始、流片倒计时、测试倒计时、记录足迹和各类统计。点「自定义组件」，可选择放在总览上方或右侧栏，拖动排序后保存。移除临时提醒组件后，提醒内容仍在，重新添加组件即可查看。倒计时可改名称和目标日期，布局随当前工作台保存。

- **文献与媒体库**集中显示原始资料和阅读笔记，可按类型筛选，也支持搜索、预览、续读和批量整理。记录也可附上 DOCX、PPT、PPTX、PDF、MD、MP4 和 MP3 原件。DOCX 预览显示正文和基础表格，媒体播放取决于编码。
- **文献引用**可离线导入和导出 BibTeX、RIS。从单条文献的「复制 / 导出引用」可复制普通或带序号的引用文本。
- **PDF 阅读器**打开时铺满软件窗口，支持滚轮连续翻页、页码跳转、缩放、目录、批注和翻译。选中文字或框选图表后，可保存为研究笔记，也可追加到已有设计问题或标题、标签、正文含「仿真」的工作／学习日志；无文字层的扫描页点「识字」框选离线识别后，也可在翻译侧栏校对文字并直接「存为研究笔记」或「追加到记录」，识别文本同时写入本机全文检索索引。记录详情的「引用资料」会展示摘录预览并回到同一 PDF、页码和选区；已被引用的 PDF 页面右上角会显示「被引用」角标，点击或在右栏切到「引用」即可反向打开引用它的记录并定位选区。拖动正文与右栏之间的分隔线即可调节右栏宽度；也可用 Tab 聚焦分隔线后按左右方向键。批注与阅读进度会随完整备份保存。
- **演示文稿（PPT / PPTX）资料库阅读与逐页批注**：打开演示文稿即进入铺满窗口的幻灯片精读工作台，左侧胶片导航栏与 `网格总览（G）` 支持快速扫览全篇、搜索幻灯片文字或筛选「仅已批注」，按 `F` 或点「全屏放映」进入沉浸全屏（全屏中亦可呼出「随手批注」浮层）。右侧栏自动提取原片演讲者备注与本页文字，每页均可记录独立批注并自动保存，支持一键「存为研究笔记」或「追加到记录」，从笔记详情可反向跳回对应页码；关闭后自动记住阅读页码并在总览「继续阅读」与资料库封面缩略图中同步显示。
- **工作日志**可以按日写，也可用「本周工作周志」续写同一篇。**学习日志**单独整理。右侧的**临时提醒**随工作台保存，可添加、勾选和删除。
- **浮窗**点击外侧可收起，再点击右下角圆形按钮恢复原位置。笔记支持自定义字号、插图和附件。

本地导入的单个附件最大 2 GB。超过 100 MB 的 PDF、PPT 和 DOCX 可下载原件后打开。JSON 和 ZIP 备份仍受 500 MB 的导入上限限制。资料较大时，完全退出软件，再复制「设置 → 资料与备份 → 查看资料目录」显示的整个文件夹。

## 文件夹与计划

各记录栏目可通过「文件夹管理」新建、编辑和嵌套目录。「文献与媒体库 → 导入文件夹」会复制所选文件及相对路径到本机库。多选后可批量移动或删除。关联资料默认显示 6 份最近资料及已选项，也可按文件夹和关键词查找。

「计划」支持一周、一个月及自定义日期。计划可关联文献与视频，也可附上代码或其他资料。在 AI 管理中为 Grok Bot 创建凭证后，助手可用 MCP 创建和更新计划。详细字段见《AI接入指南》。

在「计划」点击「导入计划」，粘贴整段回复或选取 Markdown / 文本文件。识别到 W2 之类的周次时，默认从本周一开始，可在预览中更改。正文会保留分节、清单、链接和代码，原 Markdown 作为附件保存。链接与文献库已有资料的地址匹配时，会预勾选该资料。计划仅显示起止日期。可以选择归属工作日志或学习日志，之后也能从对应日志栏目打开。

在「总览 → 自定义组件」可加入「进行中的计划」「最近计划截止」「本周计划」，并直接打开计划详情。各栏目标题下的说明可在「栏目管理」编辑，留空使用默认说明。

## 网页收藏与阅读清单

1. 进入「文献与媒体库」，点「收藏网页」并粘贴公开链接。软件会单进程并发抓取净化正文、样式与主要配图并缓存到本机（慢速外链自动限时跳过，也可勾选「极速纯正文模式」秒级存入）。
2. 打开网页卡片，可在「正文阅读」和「离线快照」之间切换。正文可调字号、版心和背景，也可选中文字做高亮或保存阅读笔记。选中正文后点「保存为研究笔记」，生成一条带回处的记录。在笔记详情点「打开原文摘录」，回到这段文字。需要在实时网页上标注时，点「原网页标注」，选中文字后点「保存所选文字」。摘录会归入原来的网页卡片。
3. 使用「阅读清单」整理专题。进入「多选」后可批量管理标签、阅读状态和清单归属。导出的阅读清单包含标题和链接，完整正文、快照和标注可用工作台备份保存。

正文和快照是独立保存在本机的附件。原网页变更或删除后，仍可读取当时已保存的部分。切换到所需视图后点「导出正文」或「导出快照」，可另存为独立 HTML。若要同时保存原有标注和关联记录，请使用工作台备份。

收藏功能面向公开网页。需要登录、受访问限制或依赖脚本渲染的站点可能无法抓取完整内容。快照保留可缓存的页面结构和部分样式，在线组件不会在离线快照中执行。

## AI 接入

1. 打开「设置 → 工作台 → AI 管理」，点击「启动并连接本机服务」。桌面版自带服务和运行环境。
2. 按需要勾选权限并创建独立助手凭证。点击「验证 MCP 接入」可检查工具是否可调用。
3. 助手提交任务后，在桌面版点「立即同步」。任务状态显示「已写入」后，可到相应栏目查看结果。

- **本机助手**使用界面显示的 MCP 地址，默认是 `http://127.0.0.1:4318/mcp`。若从 Grok Bot 执行本机命令，需要在 Grok Bot 启用并授权本机执行能力。 [Grok Bot 本机与云端说明](https://docs.x.ai/grok-bot/computer-and-apps)
- **云端助手**使用可访问的 HTTPS `/mcp` 地址和独立助手令牌。Grok Bot 云电脑的 `127.0.0.1` 指向它自己的环境。需要云端使用时，可部署服务或为本机服务配置合适的 HTTPS 转发。 [Grok 自定义连接器说明](https://docs.x.ai/grok/connectors)

桌面版启动的本机服务随程序退出而停止，凭证和待同步任务保存在当前资料目录的 `AiBridge` 子文件夹。若此前使用独立接入包，可停止新旧服务，再把旧 `runtime` 目录中的内容复制到空的 `AiBridge` 目录，之后启动桌面版。连接文件里的管理令牌由本人保管，助手使用独立助手令牌。

PDF 阅读器里的「AI 问答」使用单独的模型服务配置，支持一键套用电路精读指令、流式生成、Markdown 与 LaTeX 数学公式渲染、点击 `[第 N 页]` 胶囊回跳原文，并可将回答存为批注、存为研究笔记或追加到记录。通过齿轮 → 翻译与模型 → 翻译服务，可选择本地大模型、MyMemory、百度翻译或微软 Translator。本地大模型需要把 GGUF 文件放入 `models\translation`，完全离线运行；在线翻译和模型问答需要网络。百度需要自己的 APP ID 和密钥，微软需要 Azure Translator 密钥，免费使用可选 F0。更多操作见同目录的《使用说明》和《AI接入指南.md》。


文献库现在按文件夹浏览：根目录先显示文件夹卡片，点进去只看该文件夹里的资料，顶部面包屑可以逐级返回，右侧「全部文件」可切换成平铺列表。导入文件夹时会按目录自动建好文件夹。在文件夹上点右键可以打开、重命名、新建子文件夹或删除；删除文件夹会连同所有子文件夹和里面的资料一起删除，资料会进入回收站保留 30 天，可在那之前恢复。

阅读器支持多开：打开一份 PDF 后，标题栏下方出现标签栏，点「＋」可再打开另一份文献，标签之间随时切换，每份文献各自记住页码和滚动位置；点标签上的 × 关闭这一份。

拖动 PDF 目录右缘的分隔条可以改变目录宽度。聚焦分隔条后也可用左右方向键调整。整页对照、智能排版和排版翻译都提供独立的缩放选项。

翻译改为「选中即翻」：在 PDF 里选中文字，右侧翻译面板会自动打开、填入原文并给出译文，无需点击任何按钮；不需要时取消面板顶部的「选中即翻」即可。
