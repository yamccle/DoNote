# DoNote · 使用说明

用 Edge 或 Chrome 打开「模拟设计手记.html」即可使用。编辑器、PDF 阅读器和资料管理均可离线工作。

## Windows 桌面版

解压 DoNote Windows ZIP，双击 `DoNote.exe`。首次启用内置更新功能后，今后可在「设置 → 检查更新包…」选择新版 ZIP。普通更新只备份和替换程序文件，不重复复制资料库；安装失败会回退旧程序。资料格式需要迁移的版本会额外备份资料。当前版还没有该入口时，先完全退出软件，将新版 ZIP 解压到原程序目录并替换同名程序文件；保留 `Data` 和 `data-location.txt`。详细操作见《开始使用.md》。网页与桌面版各自保存资料。迁移时，在原网页的「备份与资料夹」导出完整 ZIP 或自包含 JSON，然后在桌面版导入。若有多个用户，请分别迁移各自的备份。

工作台和 PDF 阅读器顶部均可切换白天和夜间，设置会保留。两种模式采用黑白灰界面，栏目切换使用短淡入。笔记文字颜色及 PDF 批注颜色仍可独立设置。

## 让外部 AI 写入工作台

在「AI 管理」连接本机或云端接入服务，为每个助手选择权限并创建独立凭证。点击「验证 MCP 接入」可检查 Grok 使用的工具是否可调用。Grok 云端使用可达的 HTTPS `/mcp` 地址。助手提交先进入服务队列，工作台连接后可手动同步或自动同步，显示「已写入」时才表示记录保存完成。详见「AI接入指南.md」。

## 文献卡片与视频

文献与媒体库采用封面卡片布局，显示 PDF 首页、可读取的视频画面或图片缩略图，以及标题、作者、标签和阅读进度。封面按需生成并缓存，原文件不压缩、不改写。点击卡片直接续读或续播，右下角「详情」可编辑作者、标签等信息。视频仍通过「导入文献 / 视频」存入资料库；播放能力取决于浏览器是否支持该文件的编码。

卡片上的「删除」可移除单份资料；工具栏的「多选」可逐项勾选或「全选当前结果」，再点击「删除所选」。关联阅读笔记会保留，指向已删除资料的链接会移除。普通记录可从详情页底部点击「删除记录」，再在同一窗口确认或取消。

## PDF 目录、缩放与批注

- 阅读器左侧显示内嵌目录并支持跳转；没有内嵌目录的 PDF 会显示页码列表。可添加书签快速返回。
- 使用「＋ / −」或缩放下拉框调整大小，选择适合宽度可恢复整页宽度。
- 在正文中选择文字，再点击「高亮」「下划线」或「删除线」。保持选中，或重新选择同一段文字，再点同一按钮即可取消该标记。工具栏有黄、绿、蓝、粉、橙、紫六种颜色，可在标记前选择。
- 点击独立的「批注」入口，可查看、修改或删除批注。选中文字后，也可点击「注释」写下思考。
- 选择矩形、手绘或文字框工具后，可在 PDF 页面上拖动或点击添加标记。文字框使用右侧「批注内容」中的文字。
- 批注自动保存在本浏览器，重新打开后恢复，完整 JSON / ZIP 备份也会包含批注。可单独导出批注 JSON 留存。
- 批注保存为独立阅读数据，不直接改写原始 PDF；「下载原文件」得到的仍是上传原件。
- 扫描件没有可选文字时，文字高亮、选词翻译不能直接使用，可用矩形、手绘、文字框记录思考。

## 翻译

打开「翻译」后，直接在 PDF 中选中一句或多行文字，原文会自动填入面板，整理断行和跨行断词，保留段落。本地翻译可用时会自动显示译文。首次使用如提示准备语言包，点击「本地翻译」。选择「保存译文为批注」后，可从「批注」查看。当前环境用模拟语言包验证了自动翻译流程。

点击「在线翻译」，MyMemory 会把译文直接返回阅读侧栏。仅在点击时发送输入框中的原文，免费额度以服务商为准。也可手动修改译文并保存为文献批注。浏览器能力说明见 [Chrome 官方文档](https://developer.chrome.com/docs/ai/translator-api)。

## 旁边询问 AI

1. 打开 PDF，点击「询问 AI」，进入右侧 AI 问答面板。
2. 展开「模型服务设置」，填入支持 Chat Completions 的服务地址、模型名称和该服务要求的密钥，再点击「使用这些设置」。本地服务不要求密钥时可留空。服务需要允许浏览器连接。
3. 选择上下文：当前页文字、仅所选文字，或不附带文档。可先点击「预览将发送的内容」。如果希望解释电路图或扫描页，可主动勾选附带当前页截图，所用模型需支持图片输入。
4. 输入问题并发送，例如「这页公式中每一项的物理意义是什么」或「这个电路为何改善线性度」。仅在点击发送时，才向所设置服务发送问题与已选择的上下文。
5. 回答可保存为当前文献的批注，随资料备份；未保存的问答仅保留在当前阅读会话中。

当前未内置密钥或免费模型。必须配置自己的可用服务后，才能得到真实模型回答；接口与上下文流程已用模拟服务验证，尚未进行真实模型调用。密钥只在当前页面内存中使用，不写入记录、草稿或备份，刷新后需重新填写。服务可能产生由提供方收取的使用费用。回答需结合文献原文和实际仿真核对。接口实现参考 [OpenAI 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。

## 自动草稿与长期保存

- 编辑内容变更后，会自动暂存当前用户最近一份草稿，包括未正式提交的附件。页面底部显示暂存状态。草稿不会自动变成正式记录。
- 意外刷新后，打开「备份与资料夹」并点击「恢复最近草稿」，检查内容后点击「保存记录」。每个用户保留最近一份草稿，请及时正式保存重要内容。
- 如果原记录已被其他窗口修改，恢复草稿时会作为新记录打开，避免覆盖较新的内容。
- 同时打开多个窗口时，较旧的保存会被拒绝并提示刷新，防止悄悄覆盖更新。
- 新备份为附件增加完整性校验，导入时检测到文件损坏会停止，保留当前数据。旧版没有校验信息的备份仍可导入。
- 「备份与资料夹」会显示上次导出时间和可获取的本机空间用量。导出时间表示已发起下载，请自行确认文件确实保存在电脑中。

草稿、封面缓存和批注都在浏览器本机保存，不是外部备份，也不自动跨设备同步。长期使用仍应定期导出完整备份，并在清理浏览器数据或更换设备前备份。

## 浮窗与整页编辑

- 右上角「新建记录」使用浮窗，「整页新建」进入整页编辑。
- 编辑时可通过标题栏的「展开为整页 / 切换为浮窗」随时切换，当前内容会保留。
- 查看详情、预览附件或用浮窗编辑时，点击窗口外的遮罩或标题栏的「−」，窗口会快速缩向右下角的圆形按钮。点击该按钮可恢复原来的页码、滚动位置和编辑内容。系统启用减少动态效果时，窗口直接收起。
- 选中文字后，可设置 10–72 px 字号、加粗、斜体，以及黑、红、橙、绿、蓝、紫六种颜色，也可清除格式。
- 当前采用适合持续补充笔记的文档排版。暂不提供类似 PPT 的任意文本框、图片框画布。

## 插入图片并保留原图

1. 将光标放到正文中，点击工具栏「插入图片」。也可以粘贴剪贴板图片，或拖入图片文件。
2. 点击正文中的图片，拖动右下角手柄调整显示大小，或输入宽度百分比。
3. 图片排版栏提供居中独占一行、居左文字环绕和居右文字环绕。
4. 双击图片可打开原图，支持下载或在新窗口查看。
5. 「移出正文」只删除正文中的图片位置，原文件仍保留在附件。移除附件则会一并移除正文中的引用。

图片按所选原文件保存，不进行重编码或压缩；缩放只改变显示大小。支持 PNG、JPG、WebP、GIF、BMP，保存、重新编辑及备份恢复后仍保留图片与排版。

## 自定义栏目与研究方向

- 点击侧栏「工作台」旁的齿轮，或顶部「☷」按钮，管理栏目。
- 工作台、总览、资料库和收藏的显示名称也可以自行修改。
- 可以改名、添加新栏目、调整顺序。删除有记录的栏目时，先选择其他栏目接收记录，正文和附件会保留。
- 文献与媒体库独立保留，不随一般栏目删除。
- 保存资料或记录后，新标签会自动出现在「研究方向」，点击即可按标签筛选。侧栏沿用最多 100 项、每项 60 字的限制。
- 点击「研究方向」旁的齿轮，可添加、改名或删除标签。改名与删除会同步更新当前工作台所有使用该标签的记录，改成已有标签时会合并。手机端使用顶部齿轮。

## 文献与媒体库

1. 进入左侧「文献与媒体库」，点击「导入文献 / 视频」。PDF、视频和其他格式均可按原件归档。
2. 打开资料详情后点击「编辑记录」，补充作者 / 主讲人、来源、标签、摘要等信息。
3. 输入标题或作者搜索，也可以按标签、待读 / 在读 / 已读筛选。
4. PDF 点击阅读按钮后在站内打开，可切换页码和缩放。页码及页面内的滚动位置会自动存档，下次打开续读。
5. 视频提供站内播放器，保存播放时间，下次打开恢复位置。实际能否播放取决于浏览器对视频编码的支持；不支持时可下载原件使用本地播放器。
6. 阅读器中可手动「标记为已读」，或取消完成状态。视频播放结束也会标记完成。

记录附件区可以直接预览 PDF、PPT、PPTX、DOCX 和图片，也可播放浏览器支持的 MP4 和 MP3。PDF 使用内置阅读器。PPT 和 PPTX 按原幻灯片逐页显示，可用按钮或方向键翻页；字体、复杂图形和特效可能因浏览器而有差异。DOCX 预览显示正文和基础表格。

## 阅读笔记引用资料

- 新建或编辑阅读笔记时，可在「关联资料库中的文献 / 视频」中按标题或作者查找并勾选资料。
- 保存后，笔记详情提供原文阅读入口，不会复制上传文件。
- 资料详情中可查看相关阅读笔记，也可以直接「新建阅读笔记」。
- 删除有引用的资料后，原有阅读笔记会保留，指向该资料的链接会移除。

## 导入文件

在「设计问题」「文献阅读」「工作日志」「学习日志」等栏目点击「导入文件」，可一次选择 DOCX、PPT、PPTX、PDF、MD、MP4 和 MP3。每份文件会创建一条记录并保留原件。

- Markdown：导入正文、标题、列表、表格和常用格式，可继续编辑。若有本地图片，可与 MD 文件一起选择；文件名与 Markdown 引用匹配时会一起归档。未附带的图片会显示提示，不会自动从网络下载。
- PPTX：从附件区点击「预览 PPT」逐页阅读。新导入不生成摘录；旧记录中的自动文字摘录在详情里隐藏，手写内容和原件保留。
- 旧版 `.ppt`：保留原件，可在附件区逐页预览。

## 工作日志、学习日志和临时提醒

- 「工作日志」可选择「按日记录」「工作周志」或「组会周报」。点击「本周工作周志」可打开本周已有的周志，继续补充后续日期的进展。
- 「学习日志」使用学习主题、资料与练习、理解与疑问、下一步计划的独立模板。旧版工作学习日志归到工作日志，可编辑记录后重新分类。
- 在右侧「临时提醒」输入要做的事，按回车或点「添加」。完成后可勾选，也可删除。提醒随当前工作台保存在本机，并可随完整备份恢复。

- 「快速开始」或「工作日志」中的「本周组会」会创建整页周报。
- 预设本周工作与学习进展、汇报材料与仿真结果、问题总结与组会反馈、下周计划、待跟进事项。
- 可附上汇报 PPT，也可以插入电路图或仿真结果；导入文件后也可编辑记录并选择日志类型。
- 周报包含组会标签与周次。修改记录日期后，保存时会同步周次标签。
- 工作日志中可筛选「仅看周志 / 周报」，或按周次查看。

## 本地用户、保存与备份

点击顶部用户名称，可添加、修改、切换或删除本地用户。各用户的记录、栏目、研究方向、附件、提醒和阅读进度分开保存。删除前会显示确认；删除当前用户后会切换到剩余用户。工作台至少保留一个用户。

记录正文需点击「保存记录」提交；PDF 和视频阅读位置会自动保存。桌面版单个本地附件最大 2 GB，每条记录最多 999 个附件。超过 100 MB 的 PDF、PPT 和 DOCX 可下载原件后打开。JSON 和 ZIP 备份导入上限为 500 MB；需要备份较大资料时，完全退出软件后，复制「设置 → 查看资料目录」显示的整个文件夹。

点击顶部下载图标，打开「备份与资料夹」：

- 完整 JSON 备份：包含当前用户的记录、栏目、标签、附件、临时提醒和已存档阅读进度，可单独导入恢复。
- 离线资料夹 ZIP：包含分类原件和「离线阅读.html」，图片按排版显示，附件可直接打开；为避免重复存储大型视频，ZIP 中的 backup.json 通过路径引用原件。恢复时请导入完整 ZIP，不要单独导入其中的 backup.json。
- 保存到电脑文件夹：浏览器支持时，授权选择目录后会新建一个快照资料夹。此方式同时保存原件和自包含的 backup.json。
- Markdown：便于在其他软件阅读，文字样式采用 HTML 标记，显示效果由阅读软件决定。

导出范围是当前用户；多个用户请分别切换并备份。导入会向当前用户追加记录，相同编号会跳过。资料夹是导出时的快照，后续更改需重新导出。清理浏览器数据、更换浏览器或电脑前，请先备份。

## 旧版升级

在相同浏览器、相同文件位置打开新版时，可读取到的旧版记录会保留。若因文件位置或浏览器不同未看到旧资料，请先在旧版导出 JSON，再导入新版。

当前交付仍为离线版，尚无线上地址。
