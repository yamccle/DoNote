# DoNote 本地大模型翻译说明

DoNote 已内置 GGUF 推理组件，但不随安装包分发大语言模型。将模型下载后放到：

```text
DoNote.exe
models/
  translation/
    Qwen3-4B-Instruct-2507-Q4_K_M.gguf
    Qwen3-1.7B-Q4_K_M.gguf
    Qwen3-0.6B-Q8_0.gguf
```

推荐文件完整路径示例：

```text
H:\DoNote\models\translation\Qwen3-4B-Instruct-2507-Q4_K_M.gguf
```

## 使用

1. 在「设置 → 翻译与模型 → 翻译服务」中选择「本地大模型」，再选择已下载的模型规模。
2. 可直接在设置页点击「打开本地模型目录」。
3. 放入模型后重新打开 DoNote，设置页会显示“模型已就绪”。
4. PDF 的「整页对照翻译」工具栏可选择「快速离线」或「本地大模型」。「快速离线」使用内置的 CTranslate2 英译中模型，保留 PDF 的整页对照版式。「本地大模型」使用设置中选定的 GGUF。排版翻译在翻译服务选择「本地大模型」时使用该 GGUF。
5. 视频的「离线字幕翻译」使用安装包内置的英译中模型。

整页对照遇到异常译文时会保留该段原文，并在页码旁显示保留原文的段数。

首次翻译需要加载约 2.5 GB 权重，CPU 上会等待数秒到数十秒；后续翻译会复用已加载进程。模型完全在本机运行，翻译内容不会上传。

## 校验

在 PowerShell 中执行：

```powershell
Get-FileHash -Algorithm SHA256 "H:\DoNote\models\translation\Qwen3-4B-Instruct-2507-Q4_K_M.gguf"
```

结果应与上表的 SHA-256 一致。若文件大小或哈希不符，请重新下载。
